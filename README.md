# Automated Sales Report System

## Overview
The **Automated Sales Report System** is a Python-based tool for generating business sales reports from an Excel or Google Sheets file, providing insights into a company’s performance through automated data analysis, charts, and PDF generation.

## Features
- Load data from **Excel** or **Google Sheets**.
- Clean and validate data automatically.
- Generate charts (sales by product, revenue, top sellers, trends).
- Create a **PDF report** with metrics, charts, and analysis.
- Send PDF reports via Gmail automatically.
- Schedule reports to run daily, weekly, monthly, or custom intervals.
---
## Requirements
- Python 3.9+
- Libraries: `pandas`, `gspread`, `google-auth`, `google-auth-oauthlib`, `matplotlib`, `seaborn`, `fpdf`, `google-api-python-client`
- Install dependencies:
 ```bash
 pip install -r requirements.txt
 ```
or
```bash
 python3 -m pip install -r requirements.txt
 ```

## Setup & Usage
### 1. Local Excel Version
1. Place your Excel file inside the folder:
 ```bash
 put_excel_files_here/
 ```
2. Run the program:
 ```bash
 python main.py
 ```
3. Follow the menu prompts to configure the Excel file name (required) and optionally set the recipients, schedule, and PDF body. The report PDF will be generated in `assets/sales_report.pdf`.
---
### 2. Google Sheets Version
1. Create a Google Cloud Project and enable the **Google Sheets API**, **Gmail API**, and **Google Drive API**.
2. Create a **Service Account** and download the JSON key and rename as `service_account.json`.
3. Share your Google Sheet with the service account email.
4. Run the program and use the menu to configure the **Google Sheets** integration: choose **Change data source** option, select **Google Sheets**, and enter the sheet name.
5. Follow the prompts to generate PDF reports and optionally send them via Gmail.
6. Sending emails via Gmail (optional): <br> When you choose **Run scheduled job now** from the menu for the **first time**, the program will generate the PDF report. <br> After the PDF is created, it will ask if you want to send it by email.
<br> If you choose **yes**, you will be prompted to enter at least one **recipient email**.
<br> Then, you will be asked to authorize the program to access your Gmail account (this is the account that will send the email).
<br> If you accept, the email with the PDF attachment will be sent.

## Notes
- **Do not commit credentials** to Git (`credentials.json`, `service_account.json`, `token.pickle`).
- Excel files placed in `put_excel_files_here/` must have **.xlsx** extension.
- All generated files (PDF and charts) are stored in the `assets/` folder.
